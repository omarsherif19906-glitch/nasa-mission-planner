# NASA Mission Planner

## My Project Idea

NASA Mission Planner is a simple space-themed application designed to help organize and view information about space missions.
The application allows users to view mission details such as the mission name, destination, crew, and mission status. This could help organize mission information and make it easier to understand and track different space missions.

## Technologies and Tools

- HTML
- CSS
- JavaScript
- GitHub

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the application to view and organize NASA mission information.
